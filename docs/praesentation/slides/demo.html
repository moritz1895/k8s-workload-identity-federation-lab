Live-Demo

# einmalig

cp .env.example .env

# k3s + issuer-web + Validator starten

docker compose up -d --build

# Ende-zu-Ende-Prüfung

docker compose run --rm demo

# alles wieder entfernen

docker compose down -v

Was die Demo zeigt

  1. Discovery-Dokument von issuer-web
  2. JWKS über die jwks_uri
  3. Token ausstellen und Claims dekodieren
  4. Pod → Validator: 200
  5. Falsche Audience: 401
  6. Manipulierte Signatur: 401
  7. optional: echtes Ablaufen nach ~10 min: 401
Voraussetzung auf dem Rechner ist nur Docker mit Compose v2. Das Ablaufen (DEMO_EXPIRY=1) nur zeigen, wenn Zeit ist.
